## Краткий расклад (лучший)

- **14 млн ₽** — депозитная лестница (ставки топ-10 ЦБ, сент. 2026 ≈ 13%)
- **6 млн ₽** — длинные ОФЗ-ПД на **ИИС-3**, закрытие не раньше **2031**
- Через **3 года** — изъятие **10 млн ₽** с депозитной части
- Цель дохода: **≥ 100 000 ₽/мес** до **2040**

> Это персональный финансовый план-модель, не индивидуальная инвестиционная рекомендация. Перед сделками сверьте актуальные ставки, НКД и налоговый статус с брокером/налоговым консультантом.
