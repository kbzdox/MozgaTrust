## Краткий расклад

- База **20 млн ₽** → депозит + ИИС (ОФЗ); доля считается под макс. рост за 3 года при условии изъятия **10 млн** и пенсии **100к/мес**
- **V1** (~11,7 млн депозит / ~8,3 млн ИИС) — пенсия с 1-го месяца  
- **V2** (~8,7 млн депозит / ~11,3 млн ИИС) — пенсия после 3 лет  
- Через **3 года** — изъятие **10 млн** с депозита; ИИС до **2031**
- Таблицы с проверкой формулы: [plan/CASHFLOW.md](plan/CASHFLOW.md)

> Это персональный финансовый план-модель, не индивидуальная инвестиционная рекомендация. Перед сделками сверьте актуальные ставки, НКД и налоговый статус с брокером/налоговым консультантом.
